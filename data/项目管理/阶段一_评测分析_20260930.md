## 一、全链路梳理（数据输入→策略计算→信号生成→执行→风控→复盘）

```
Hermes Cron Scheduler (~/.hermes/cron/jobs.json)
        │
        ▼
main.py::main() ──(CLI: news/screen/review/skeptic/decision/full/weekly/portfolio/event)
        │
        ├─ MemPalace.wake_up()  ← data/memory 跨天记忆
        ├─ 交易日守卫 is_trading_day()
        ├─ 长假恢复检测 F08 (gap>3天 → 跳过Skeptic)
        ▼
run_phase("news_only")  NewsAgent          ← LLM调用#1，熔断器守卫
        │ 质量门控：success=False → 终止全流程（硬阻塞 ✅）
        ▼
MarketAgent.run()                        ← 0次LLM，抓取五池+3指数(sh000001/sz399001/sz399006)
        │ → data/shared_memory.json {代码,名称,涨跌幅,最新价,...}
        ▼
PoolManager 池价格刷新（重点池/持仓池/候选池，3次独立try）
        ▼
ScreenAgent 快筛 → 快筛候选池(≤20)        ← LLM#2，熔断器守卫
        │ 失败 → 级联终止
        ▼
ReviewAgent 四维审查+过热+ML前置          ← LLM#3，熔断器守卫
        │ 评分≥75→重点观察池；<65→边缘池
        ▼
LLM截断检测 → 市场状态5档（decision_agent._get_market_state）
        ├─ 偏多/震荡偏强/震荡 → SkepticAgent LLM质疑   ← LLM#4，熔断器守卫
        └─ 震荡偏弱/偏空      → 弱市简化审查（零LLM规则引擎）
        ▼
DecisionAgent 决策 → S级操作池(≤3)+决策报告.md+decision_log.json  ← LLM#5，熔断器守卫
        ▼
池清理（候选池≥14天/边缘池≥30天） → 条件单扫描OrderEngine → 合规日结
        ▼
五池健康审计 → 全池低分扫描sweep_all_pools → 准确率刷新 → MemPalace保存 → 飞书卡片
```

| 节点 | 异常分支 | 实测状态 |
|---|---|---|
